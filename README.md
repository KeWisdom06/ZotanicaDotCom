# ZotanicaDotCom
An (unfinished) static clone of an artist merch site, built with HTML and CSS as a warm-up project for learning frontend development. No backend or e-commerce functionality implemented yet.

**Please note: This project is a non-commercial learning exercise, not affiliated with Mach-Hommy, his site or his brand. The real [Zotanica.com](https://zotanica.com) is used as a learning guide and as a reference only**
